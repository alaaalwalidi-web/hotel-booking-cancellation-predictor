# 🏨 Hotel Booking Cancellation Predictor

## 📌 What is this?
This project predicts whether a hotel booking will be canceled using machine learning.

## 🔧 What I did
- Cleaned and prepared the dataset
- Built machine learning models
- Selected Random Forest as the best model
- Built an interactive dashboard using Streamlit

## 🚀 How to run

Install libraries:
pip install -r requirements.txt

Run the app:
streamlit run app.py

## 📁 Project Files
- train_model.py → data cleaning and model training
- app.py → dashboard
- model.pkl → trained model
- columns.pkl → feature columns

## 📊 Result
The model can predict if a booking will likely be canceled or not.
